# HBBA v1.0.1 — GitHub public-clean release

## RU

Этот пакет создан из финального HBBA v1.0.1, но намеренно сокращён для публичного GitHub-репозитория.

### Включено

- рабочий статический интерфейс HBBA;
- frozen Scientific Core v0.7.0.28;
- канонический project/scientific status;
- evidence registry, edge audit, schemas и публичные AI prompt contracts;
- финальные публичные результаты Challenge и Composition;
- компактная воспроизводимая проверка public release;
- большой двуязычный GitHub README;
- правила contributions и privacy/security.

### Намеренно исключено

- private Composition hidden truth и answer mappings;
- randomization/master secrets;
- model-facing generation packages и private evaluation package;
- bulk historical intermediate audit artifacts и failed candidate packages;
- временные локальные build-файлы и ZIP;
- локальные пути и conversation exports.

Scientific Core при подготовке public-clean package **не изменялся**.

## EN

This package is derived from the final HBBA v1.0.1 release but intentionally reduced for public GitHub use.

### Included

- runnable static HBBA interface;
- frozen Scientific Core v0.7.0.28;
- canonical project/scientific status;
- evidence registry, edge audit, schemas, and public AI prompt contracts;
- final public Challenge and Composition research outputs;
- compact reproducible public-release validation;
- long bilingual GitHub README;
- contribution and privacy/security guidance.

### Intentionally excluded

- private Composition hidden truth and answer mappings;
- randomization/master secrets;
- model-facing generation packages and private evaluation package;
- bulk historical intermediate audit artifacts and failed candidate packages;
- temporary local build files and ZIPs;
- local paths and conversation exports.

The Scientific Core is **not modified** by the public-clean packaging step.
