# Security and privacy / Безопасность и приватность

## RU

HBBA — локальное статическое научно-образовательное приложение. Для основной работы интерфейса backend не требуется.

При создании Issue или Pull Request **не публикуйте**:

- материалы реальных кейсов, позволяющие идентифицировать людей;
- API keys, пароли, tokens и приватные URL;
- неопубликованные benchmark secrets или hidden reference answers;
- private conversation exports;
- локальные конфигурации с персональными путями/учётными данными.

Для обычной программной ошибки приложите минимальный воспроизводимый пример и версию HBBA.

---

## EN

HBBA is a local static scientific/educational application. The core interface does not require a backend.

When opening an Issue or Pull Request, **do not include**:

- real-case material that identifies people;
- API keys, passwords, tokens, or private URLs;
- unpublished benchmark secrets or hidden reference answers;
- private conversation exports;
- local configuration containing personal paths or credentials.

For ordinary software defects, provide a minimal reproducible example and the affected HBBA version.
