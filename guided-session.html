Guided Session — это сопровождаемый разбор, а не просто генератор JSON.
Скопируйте MASTER SPEC в новый чат. Это обязательный state machine: факты → отдельный .json-файл → локальный импорт → STOP → только после сообщения «загрузил» → ровно один шаг экскурсии за обычный ответ. Ни один запрос пользователя не должен обходить этот gate.
1 · Копируете Prompt

Вставляете его в новый чат с ИИ. Модель сначала объясняет процесс и задаёт один вопрос: что произошло?

2 · ИИ собирает факты

Уточняет наблюдаемые события, участников и альтернативы. Не должен сразу выдумывать скрытые мотивы.

3 · Получаете .json-файл

ИИ обязан создать отдельный HBBA-SCENARIO-3 .json. Просто показать JSON в сообщении — fallback, а не основной путь.

4 · Загружаете в HBBA

Сценарий → Загрузить JSON-файл → Проверить → Показать на карте. Можно также вставить JSON вручную.

5 · Пишете «загрузил»

До этого ИИ должен ждать. После подтверждения начинается объяснение по шагам Guided Tour.

6 · Идёте по карте

ИИ говорит, куда смотреть и когда нажать «Следующий». Новые факты → новый versioned .json-файл и повторная загрузка.
